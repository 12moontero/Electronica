# Zumbador Pasivo

> **Descripción:** Un zumbador pasivo es un altavoz electrónico que, dependiendo de qué frecuencia tenga, es más grave o más agudo.

## Esquema de conexión
Es fácil de conectar, tienes que poner tu cable con corriente a una pata y la otra pata tiene que salir al negativo.

## 💡 Nota 
* **Lo difícil de este componente es programarlo en C++, solo se puede programar con PWM**
